---

Model = DeepSeek V4.1 Flash

SYSTEM = "Você é um agente de desenvolviento de software"

## Contexto

Implemente um sistema pomodoro simples em html css js.

Siga rigorosamente a Especificações abaixo. Não adicione funcionalidades que não foram solicitadas.

# Especificações - Método Pomodoro

## Objetivo
Criar ma aplicação de método pomodoro simples para gerenciamento de estudos

## Requisitos Funcionais
1. O usuário deve conseguir iniciar um ciclo Pomodoro.

2. O período de trabalho deve ser definido pelo usuário, que poderá escolher entre 25, 40 ou 50 minutos.

3. Após o período de trabalho, o sistema deve iniciar
   uma pausa de 5 minutos.

4. Após a pausa, o ciclo deve ser encerrado.

5. O sistema deve informar ao usuário quando:
   - o período de trabalho começar;
   - o período de trabalho terminar;
   - a pausa começar;
   - a pausa terminar.

6. O sistema deve permitir iniciar um novo ciclo após
   o término do ciclo anterior.

# Requisitos não funcionais

1. O temporizador deve realizar a contagem do tempo de forma contínua, sem exigir interação com o usuário durante a contagem

## Restrições

- utilizar html css js

- não utilizar banco de dados

- não adicionar funcionalidades que não sejam na Especificações

Antes de implementar, analise os requisitos e depois crie o código completo do sistema.

# Experimento
Realizei duas implementações

## Implemetação 1

Na primeira implementação, a duração do período de trabalho não foi especificada de forma explícita. Foi utilizada a seguinte frase:

```txt
"O período de trabalho deve possuir uma duração definida para o ciclo".
```

Essa especificação não determinava qual deveria ser a duração do período de trabalho. Dessa forma, o agente precisou interpretar um requisito que não estava definido explicitamente.

Com isso, como resultado, o agente adotou o comportamente para uma duração fixa de 25 minutos, considerando o tempo tradicionalmente associado ao método Pomodoro.

## Implementação 2

Na segunda implementação, o requisito foi especificado de forma mais precisa:

```txt
"O período de trabalho deve ser definido pelo usuário, que poderá escolher entre 25, 40 ou 50 minutos."
```

A partir dessa especificação, o agente realizou as alterações necessárias na implementação, adicionando as três opções de duração para o período de trabalho: 20 min, 40 min e 50 minutos.

# Conclusão
Foi concluído que a precisão da especificação influencia as decisões tomadas pelo agente durante a implementação.
