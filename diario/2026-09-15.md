# O agente
O agente é definido como um Assistente de consulta de dados acadêmicos de alunos.  As diretrizes a serem seguidas foram determinadas para que o agente não invente dados e obter somente informações através das ferramentas, e se necessário, consultar primeiro 'listar_alunos' antes de buscar os detalhes, e em caso de erro, informar de forma clara direta sem adivinhar a resposta.

# Ferramentas (tools)

```
def listar_alunos(): Lista os nomes de todos os alunos cadastrados. 
```

```
def dados_aluno(nome: str): Retorna a nota e o número de faltas de um aluno específico.
```

## Análise da Primeira Resposta do Agente
Ele retornou de forma direta em dois passos.
```txt
--- passo 1 ---
tool chamada: dados_aluno({'nome': 'Carla'})

--- passo 2 ---
Resposta final: A nota da Carla é 9.2 e ela não tem faltas.

(total de passos usados: 2)
```

# Ferramentas piorada (tools)

```
def listar_alunos(): Lista os nomes de todos os alunos cadastrados.  
```


```
def dados_aluno(nome: str): Faz uma consulta.
```

## Análise da Segunda Resposta do Agente

```txt
--- passo 1 ---
tool chamada: dados_aluno({'nome': 'Carla'})

--- passo 2 ---
Resposta final: A nota da Carla é 9.2 e as faltas são 0.

(total de passos usados: 2)
```


# Conclusão
Nesse caso em específico, o modelo conseguiu acertar a ferramenta correta(`dados aluno`) mesmo com a descrição vaga ("Faz uma consulta com um parâmetro"). 

Então a degradação da descrição não significa que a descrição não importa, mas que as condições importam, pois se talvez adicionássemos mais tools, talvez o modelo tivesse mais concorrência ou se as perguntas fossem mais ambíguas se não citássemos diretamente "notas e faltas". 

Com isso, a descrição vaga não atrapalhou porque outras pistas fortes como, nome da função, parâmetros, pergunta clara, compensaram o raciocínio.
